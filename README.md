# Servidor Protótipos STEM Criar

Este repositório armazena o código do Servidor de controle dos Protótipos desenvolvidos pelo time Stem Criar.

Para rodar o servidor:

1. Baixe o .zip;

2. Descompacte a pasta baixada:`servidor-prototipos-main`;

3. Abra a pasta e procure o arquivo `run`

4. Clique duas vezes neste arquivo `run`

5. Em poucos segundos, o **Servidor STEM Criar** abrirá em seu navegador
